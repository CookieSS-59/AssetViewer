# Asset Viewer

## Overall Info:

Asset viewer is just a vibe coded software where you can quickly well, find and view files in a viewport GUI. (Simillar to AssetStudio) It was supposed to be keept as a private project for when i quickly want to explore decompiles/files of unity games alltho it is capable with other file extentions

## Supported Files:

- Images: PNG, JPG/JPEG, BMP, TIFF, ICO, GIF, and TGA
- Animated GIF: play/pause, restart, frame seek, and playback speed
- Audio: WAV, MP3, WMA, OGG/OGA, Opus, FLAC, AAC/M4A, AIFF, MIDI, CAF, and AMR. Internal decoding depends on Windows codecs; use the external-player fallback when a codec is unavailable.
- Video / animation clips: MP4, M4V, MOV, AVI, WMV, MPG/MPEG, WebM, and MKV when supported by Windows codecs; external-player fallback is available.
- 3D models: OBJ, ASCII/binary STL, OFF, ASCII PLY, static Collada DAE, glTF 2.0, and GLB 2.0
- Unity project data: ASSET, META, PREFAB, UNITY scenes, MAT, ANIM, CONTROLLER, INPUTACTIONS, SHADERGRAPH, ASMDEF/ASMREF, importer settings, and related serialized files
- Text/code: C#, C/C++, Lua, Python, JavaScript/TypeScript, Java, Kotlin, Go, Rust, Ruby, JSON, XML/XAML, shaders, Markdown, YAML, TOML, INI, PowerShell, batch, HTML/CSS, SQL, logs, and more
- Binary game files such as FBX, Blender, Unity packages, bundles, resource files, and 3DS show metadata and a short hex header when geometry decoding is unavailable
